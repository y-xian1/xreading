# xreading

一个用于英语精读的小工具：先自己逐句翻译，再对照参考译文，最后在全文里复习并做标记和备注。

## 使用

1. 打开页面，粘贴一篇英文文章（或选择 .txt 文件）。
2. 生成参考译文：在「设置 → 翻译接口」填写自己的接口地址、API Key 和模型名后点「用 API 生成」；也可以直接粘贴已有的中文译文，系统会自动切分并对齐。
3. 逐句输入自己的翻译，确认后查看参考译文。选中英文原句中的文字，可以添加荧光笔、下划线、波浪线或备注。
4. 学完后进入全文页复习，点击句子可在右侧查看你的译文、参考译文和备注。

## 关于数据

- 所有内容只保存在你自己浏览器的本地存储里，不会上传到任何服务器。
- API Key 同样只保存在你的浏览器里，不会写入代码或备份文件。
- 在「设置 → 数据保存」里，可以把文章自动备份到电脑上的一个文件夹（需要 Chrome 或 Edge），也可以手动导出和导入。

## 本地运行

无需安装任何东西，下载 `index.html`，用浏览器打开即可。
